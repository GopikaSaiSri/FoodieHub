# FoodieHub – Responsive Food Ordering Website

## Lab Experiment 3: Responsive Layout with Grid & Flexbox

### Objective
To develop a mobile-first responsive food ordering website using CSS Grid and Flexbox.

### Features
- Responsive website header and navigation bar.
- Food categories section.
- Six restaurant cards.
- CSS Grid for restaurant listings.
- CSS Flexbox for navigation and categories.
- Hover effects on restaurant cards.
- Media queries for mobile, tablet and desktop layouts.
- Container queries for responsive card styling.

### Technologies Used
- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Media Queries
- Container Queries
